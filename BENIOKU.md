# AIHEAR Akademi: Türkçe video üretimi (AIHEAR Odyoloji Akademisi)

Bu depo yalnızca AIHEAR Odyoloji Akademisi'nin Türkçe videolarını GitHub Actions ile üretmek için vardır.
Ders metinleri ve görseller AIHEAR'a aittir; izinsiz kullanılamaz ve dağıtılamaz.

Ses: Microsoft Edge çevrimiçi sesi `pt-BR-ThalitaMultilingualNeural` (Türkçe, cümle başına önek seçimi `emma_sec.py`).
Fontlar: Inter ve Outfit (SIL Open Font License).
